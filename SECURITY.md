# Security Policy

Xentrolance Technical Labs takes the security of our software and the systems we build seriously.

## Supported Versions

Security updates are provided for the latest release of each actively maintained public repository unless a repository states otherwise.

## Reporting a Vulnerability

Please **do not** disclose security issues publicly.

Email **hello@xentrolance.com** with:

- Repository name and affected component
- Description of the vulnerability
- Steps to reproduce or a proof-of-concept
- Potential impact assessment
- Your preferred contact details

We aim to acknowledge reports within **72 hours** and will keep you informed as we investigate and remediate.

## Responsible Disclosure

We appreciate researchers who:

- Give us reasonable time to fix issues before public disclosure
- Avoid privacy violations, data destruction, and service disruption
- Do not access data that is not their own

## Prefer Encrypted Contact?

If you need a more private channel, mention that in your initial email and we will arrange a secure follow-up.
